# Sistema-de-OS-para-Tape-aria-Marzorati
Projeto integrador 1 da faculdade de Big Data para negócios, na Fatec Ipiranga, programa em Python com banco de dados PostgreSQL.

O projeto cria páginas de administração básica do negócio, com janelas para ordens de serviço, cadastro e listagem de clientes e fornecedores, movimentações financeiras de vendas e compras de produtos ou materiais se conectando aos dados de clientes e fornecedores já cadastrados, é possível buscar dados do banco, inserir, 'deletar', e afins.

Foi criado também um instalador, amigável para leigos, que instala o programa, cria o atalho na área de trabalho, instala o postgre e cria e conecta o banco de dados. Deixando tudo pronto para o usuário final.

Na pasta você vê, os scripts do banco, o script que realiza a instalação via comandos CMD, o instalador do postgre e o executável do programa em si.

Sei que é simples, mas pode vir a ser algo, ou ser útil para alguém, licença livre, em caso de dúvidas estarei a disposição.
